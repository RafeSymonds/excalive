excalive

Hand-drawn slide decks and narrated videos from one markdown file. Each video below is a story.md and a folder of Excalidraw scenes. A local voice, Kokoro, reads each section of the story while its step draws in.

How a browser finds a website

One arrow per step as the resolver asks the root, TLD and authoritative servers, then caches the answer, and the camera moves in on the cache while the title stays put. Blue asks, gray refers, green is the address.

How a view counter counts

  • 1:27
  • story.md
  • scenes
  • effects.mjs

One web request, from the click to the count. The camera moves in on the database while 41 counts up to 42, the new count goes back to the page, and a thousand visits later both read 1,042. The count is an effect the story defines in its own effects.mjs.

A leaderboard that sorts itself

  • 1:41
  • story.md
  • scenes
  • screenshots

Screenshots of a real web page sit in the scene, with a hand-drawn ring on the row being discussed. Then a new score goes through the code in four steps, and the bars sort twice: as text, which leaves 100 last, then as numbers, which puts Grace first.
